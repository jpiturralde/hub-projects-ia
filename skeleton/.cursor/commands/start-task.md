# Iniciar tarea

1. Pedir o confirmar un único objetivo y dominio.
2. Leer `PROJECT-CONTEXT.md`.
3. Leer el índice o archivo canónico principal del dominio.
4. Seleccionar hasta dos archivos adicionales; no abrirlos todavía si no son necesarios.
5. Consultar Engram por decisiones previas relacionadas cuando esté disponible.
6. Proponer un plan breve e indicar el contexto que se cargará.

Si el usuario cambia de dominio, recomendar un chat nuevo.
